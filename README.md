# Supply-Chain-Dashboard
Supply chain analysis using Power BI
About the Project

This dashboard provides an overview of supply chain performance, including product costs, quantity sold, transportation, locations, and product quality.

Key Insights

Total supply chain cost is approximately 53K.

The dashboard covers 100 SKUs.

The average defect rate is 2.28.

Total quantity sold is 4,922.

Road transportation has the highest quantity sold.

Route B has the highest total cost among the three routes.

Out of 100 SKUs, 23 passed inspection, 36 failed, and 41 are pending.

Tools Used

Power BI, DAX, Data Visualization

Conclusion

This dashboard helps analyze supply chain costs, track product quality, and understand transportation performance to identify areas for improvement.
